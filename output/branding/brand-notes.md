# xDev Hive identity

The selected identity is **X + HIVE**, extending the [xDev brand](https://xdev.asia/brand/). The original blue X is retained and HIVE uses custom uppercase SVG paths with the same stroke width, cap height and rounded joins as DEV.

## Production assets

- `xdev-hive-light.svg`: transparent logo for light backgrounds; lettering `#344568`.
- `xdev-hive-dark.svg`: transparent logo for dark backgrounds; lettering `#E8ECF8`.
- Matching PNG exports and `xdev-hive-preview.png` provide previews.
- Light X gradient: `#7BD4FF` → `#1E90FF` → `#004CFF`.
- Dark X gradient: `#B8F1FF` → `#3FA9FF` → `#1C58FF`, preserving the original dark xDev asset.
- Suggested dark background: `#142745`.

Preserve the X, gradient and proportions. Leave clear space of at least one quarter of the X height. Use the standalone parent-brand X where the full wordmark cannot remain readable.

The original X uses `Space Grotesk, Inter, sans-serif` with weight 600. Install the same font for identical rendering; PNG previews currently use the locally available fallback font. HIVE lettering consists of paths and does not require a font.
