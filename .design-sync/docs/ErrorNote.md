# ErrorNote

Shows the error of a failed action as a destructive alert, keeping line breaks. It renders nothing when `error` is empty, so it can sit permanently above a form.

**Key props**: `error`: `string | null | undefined`.

```tsx
<ErrorNote error="Không giao được task: máy hc-duytd20-linux đang hết quota." />
```
