# HiveWordmark

The xDev Hive identity: the gradient xDev X with HIVE / DEV HUB lettering, drawn inline as SVG. The lettering colour follows the theme (the `dark:` variant). Keep it at least 24px tall; below that use `XMark`. Never redraw or recolour it.

**Key props**: `height` (default 30); `className`.

```tsx
<HiveWordmark height={32} />
```
