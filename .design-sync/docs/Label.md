# Label

The form label (Radix Label, 13px medium). Point `htmlFor` at the control's `id`; add `className="font-normal"` when it labels a checkbox or switch inline.

```tsx
<Label htmlFor="task-title">Tiêu đề</Label>
<Input id="task-title" defaultValue="Thêm bộ lọc theo máy" />
```
