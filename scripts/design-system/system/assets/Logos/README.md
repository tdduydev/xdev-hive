The xDev Hive marks, copied unchanged from the repository. Never redraw or recolour them.

- `hive-light.svg` — X + HIVE / DEV HUB wordmark for light grounds (`bg-canvas` light, `surface-1`). Lettering ink #344568 (`brand-ink`).
- `hive-dark.svg` — the same wordmark for dark grounds. Lettering ink #e8ecf8 (`brand-ink-inverse`).
- `xdev-hive-dark.svg` — the wordmark as the app ships it on dark grounds (X as live Space Grotesk text with a soft glow). Lettering #e8ecf8.
- `app-icon.svg` — the app icon / favicon: the X outlined in the light-blue gradient on a `brand-navy` rounded tile. Use below 24px and wherever an exact X matters.
- `x-mark.svg` — the X alone in the #7bd4ff → #1e90ff → #004cff gradient, set as live text (falls back to Inter when Space Grotesk is absent).

Keep the wordmark at least 24px tall; below that use `app-icon.svg` or `x-mark.svg`.
