# Notices

xDev Hive bundles agent skills written by other projects. Each skill folder keeps its upstream license file and a
`SOURCE.md` with the repository, commit and license.

## Hive default skills (`packages/skill-pack/`)

Shipped with the hub and shown on the Skills page as "Hive mặc định". The list, licenses and attribution come from
[tdduydev/xdev-skills](https://github.com/tdduydev/xdev-skills) (`library/`) at the commit pinned in
`packages/skill-pack/pack.json`; see [packages/skill-pack/NOTICE.md](packages/skill-pack/NOTICE.md) for the per-skill
table. Licenses in the pack: MIT, Apache-2.0, and CC BY-SA 4.0 for the two Trail of Bits skills (`differential-review`,
`sharp-edges`), whose text stays under CC BY-SA 4.0.
